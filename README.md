## Publish

1. Create a **public** repo named **`GSimoes2319.github.io`** on GitHub (must match your username).
2. Push this project to `main`:

   ```bash
   cd C:\Users\Gaspar\Projects\work-profile
   git init
   git add .
   git commit -m "Add personal profile site"
   git remote add origin https://github.com/GSimoes2319/GSimoes2319.github.io.git
   git push -u origin main
   ```

3. **Settings → Pages** → deploy from branch **`main`**, folder **`/ (root)`**.
4. Site URL: **https://gsimoes2319.github.io** (GitHub usernames are case-insensitive in URLs).
